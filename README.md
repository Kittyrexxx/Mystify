# Mystify

100% free & open-source CLI utility.

## Features
- Interactive search-filterable TUI menu
- Encoding & decoding (Base64, Hex, Binary, Octal, URL, ASCII/Decimal, ROT 1-25, Morse, Atbash, A1Z26, Reverse, Leetspeak, plus smart auto-detect decode)
- Extractors (emails, URLs, IPs, phone numbers, hex colors, Discord invites)
- Network tools (ping, DNS lookup, local IP, flush DNS)
- Privacy tools (3-pass file/folder shredder)
- Auto-updates from GitHub releases

## Usage
Grab the pre-compiled `.exe` from the Releases page and run it.

If you want to build it yourself:
In command prompt CD to the folders, Then run ```cargo build --release```
